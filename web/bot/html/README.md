# HTML-карточки Vivid

`BOT_STYLE=html` включает карточки для всех пользователей. Режим `legacy`
использует rich-сообщения Telegram. Персональный выбор вида больше не нужен.

Шаблон выбирается через `BOT_HTML_TEMPLATE=default`. Файлы лежат в
`WEB_DIR/bot/html/<имя>/`:

- `style.css` — дополнительные CSS-правила поверх встроенной темы;
- `interface.html` — необязательный полный HTML-шаблон.

Без `interface.html` у `default` используется встроенный документ. Чтобы
начать собственный шаблон, скопируйте
`internal/bot/widgets/interface.html` в эту папку, сохранив все `id` и
JavaScript `createVividWidget`. Неизвестное имя и неполный документ отклоняются
с ошибкой, а не подменяются другим шаблоном.

`BOT_HTML_THEME=telegram` сохраняет цвета клиента. Можно менять размеры,
компоновку и шрифты в CSS, используя `var(--tg-theme-text-color)`,
`var(--tg-theme-bg-color)`, `var(--tg-theme-button-color)` и другие переменные.
`BOT_HTML_THEME=custom` также разрешает акцент из `bot-theme.json`.
Проектный CSS загружается последним и может переопределить любые цвета.

`{{MASCOT_URL}}` заменяется на HTTPS-адрес изображения Ви. Изображения взяты
из `vivid-bot/customization/assets`, исходный персонаж сохранён. Для реального
виджета нужны `SITE_ENABLED=true` и публичный HTTPS `SITE_BASE_URL`; маскот
отдаётся через `/static/bot-mascot/vi-peek.webp`. В автономном каталоге картинка
встроена. Большие изображения нельзя встраивать в сам Telegram-виджет.

Динамика передаётся в приватном `TelegramWidget.chatData`. Поля страницы:
`t` — заголовок, `s` — состояние, `k`/`v` — основная величина,
`n` — пояснение, `x` — текст, `m` — факты, `b` — кнопки,
`used`/`limit` — занятые/доступные места, `hero` — блок Ви.
Сегменты мест рисуются из `used` и `limit`; для больших лимитов показываются
до 20 сегментов и точные числа в подписи. Не используйте сегменты как
самостоятельный источник данных для бизнес-решений.

Кнопка может иметь `checked: false/true` и стиль `checkbox`. Она доступна
с клавиатуры и сообщает своё состояние через `aria-checked`. Нажатие отправляет
проверяемое действие серверу, а не меняет условия оплаты только в браузере.

Сервер проверяет размер: HTML до 32 KiB, zlib до 4 KiB, приватные данные
страницы до 1 KiB. Изменение файла создаёт новый хеш оформления: новую
карточку бот сначала отправляет и сохраняет, потом удаляет предыдущую.
Если отправка нового документа запрещена Telegram, совместимая старая
карточка остаётся рабочей. Возможность отправки зависит от Telegram.

Изолированное оформление обычного режима находится в `internal/botui/legacy`,
клиент rich API — в `internal/botui/legacy/transport`. В них нет выдачи
подписок и расчёта платежей. Разделение пакетов не является отдельной сборкой
без legacy; пока оба рендерера входят в приложение.
