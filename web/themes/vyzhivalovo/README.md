# Берлога — резервная тема для сверки

Это альтернативное оформление от проекта «Выживалово». Оно хранится в main
как неизменяемый резерв и контракт совместимости для последующих обновлений;
оно не является оформлением по умолчанию и не включается в рабочих окружениях
без явной настройки `WEB_DIR`.

## Исходное описание

Тёплый графит, спокойный красный акцент и знакомая лесная сцена из предоставленного архива. Рабочие страницы остаются простыми: читаемые подписи, крупные элементы управления, заметные состояния и минимум декоративных слоёв. Есть светлый режим; выбор хранится только в браузере.

## Подключение

```dotenv
WEB_DIR=web/themes/vyzhivalovo
BRAND_NAME=Берлога
BOT_STYLE=legacy
RICH_MESSAGES_ENABLED=true
```

После выбора темы перезапустите приложение. `WEB_DIR` должен существовать внутри среды запуска; для Docker смонтируйте каталог темы и укажите путь внутри контейнера. Бренд, контакты и юридические настройки приложения имеют приоритет над файлом темы.

В рабочем Telegram-режиме применяется `bot.json` и обычные rich-сообщения с нативными кнопками Telegram. `bot-theme.json` и `bot/html/default/style.css` оставлены только для проверки обратной совместимости экспериментальных карточек; включать `BOT_STYLE=html` для рабочих ботов не нужно. Чужой персонаж Ви в этой теме скрыт.

Включение темы не меняет тарифы, аккаунты, платежи или права сотрудников. Выбор автопродления, CSRF, статусы заказов и поддержка используют существующие обработчики Go.

## Локальный просмотр

Автономный каталог 42 экранов бота без БД и внешних API:

```powershell
New-Item -ItemType Directory -Path .codex-attachments -Force
go run ./cmd/screenlab -export .codex-attachments/berloga-bot.html -web-dir web/themes/vyzhivalovo
```

Веб-стенд требует отдельной локальной БД `vivid_ui_lab` на порту 55439. Используйте выделенную схему с правами своего демонстрационного пользователя:

```powershell
$env:VIVID_LAB_DATABASE_URL='postgres://review_user:password@127.0.0.1:55439/vivid_ui_lab?sslmode=disable&search_path=vyzhivalovo_preview'
go run ./cmd/screenlab -serve -port 8097 -web-dir web/themes/vyzhivalovo
```

Команда проверяет имя и локальный адрес БД. Авторизация демонстрационного аккаунта существует только в `cmd/screenlab`; рабочий сервер её не использует. Платёжный API и панель на стенде заменены локальными заглушками. Данные устройств не удаляются, списания не выполняются, Telegram не запускается. Не выставляйте стенд наружу и не используйте его вместо `cmd/vivid`.

## Файлы

- `theme.json` — палитра, навигация и содержание главной.
- `templates/components/berloga.html` — главный экран, возможности и динамические тарифы.
- `static/berloga.css` — оформление сайта и админки, адаптация от 320 px.
- `static/berloga.js` — переключение светлого/тёмного режима и текущее положение в навигации.
- `bot.json`, `bot-theme.json`, `bot/html/default/style.css` — Telegram.

Логотип и лесная иллюстрация взяты из предоставленного пользователем архива `vivid-bot-full-2026-11-15.tar.gz`, из `customization/assets/logo.png` и `hero-bg.webp`. Изображения не перерисовывались. Права на них сохраняются за их владельцами. Другие материалы, конфигурация, история Git и дампы БД из архива в тему не включены.
